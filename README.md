# Bridger Hub (BW)

A modular, high-performance automation and combat framework for Roblox.

---

## Quick Launch

### Option 1: Standalone Single-File Bundle (Recommended)
Zero external dependencies. Works out-of-the-box in any Luau executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/opim80/BWtest/main/scripty_bundle.luau"))()
```

### Option 2: Modular Web Loader
Loads all 13 modules dynamically from GitHub and caches them locally:

```lua
-- Optional: override default repository
getgenv().BW_GITHUB_REPO = "opim80/BWtest"
getgenv().BW_GITHUB_BRANCH = "main"

loadstring(game:HttpGet("https://raw.githubusercontent.com/opim80/BWtest/main/scripty.luau"))()
```

---

## Project Structure

- `scripty.luau`: Main modular loader with local `readfile` and remote GitHub `HttpGet` fallback.
- `scripty_bundle.luau`: Standalone single-file bundle generated by `bundle.py`.
- `bundle.py`: Advanced Python bundler that encapsulates modules into function closures.
- `modules/`: All 13 isolated feature modules (Core, Utils, Logging, Config, Movement, Safety, Fishing, Automation, Visuals, Saint, UI, Combat, Tabs).

---

## Bundling Changes

Whenever you edit any file under `modules/`, re-generate the standalone bundle by running:

```bash
python bundle.py
```
